# LAPORAN PRAKTIKUM 4 — CSS LAYOUT

## 1. Membuat Folder Project
Langkah pertama adalah membuat folder project dengan nama `Lab4_layout` di Visual Studio Code. Folder ini digunakan untuk menyimpan seluruh file yang dibutuhkan dalam pembuatan website, yaitu `home.html`, `style.css`, `about.html`, dan `kontak.html`.
![images](media/Screenshot%202026-10-27%20120438.png)

## 2. Membuat File home.html
File `home.html` merupakan halaman utama website yang dibuat menggunakan HTML. Kode di dalam file ini berfungsi untuk membentuk struktur dan menyusun konten website, mulai dari bagian header, navbar, hero panel, layout tiga kolom, artikel, sidebar, hingga footer.
Elemen HTML seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>` digunakan untuk membagi halaman berdasarkan fungsinya. Sementara itu, elemen `<a>` digunakan untuk membuat tautan navigasi menuju halaman lain.
File `home.html` juga dihubungkan dengan file `style.css` agar struktur HTML yang dibuat dapat ditampilkan dengan desain yang lebih menarik.

## 3. Membuat File style.css
File `style.css` berfungsi untuk mengatur tampilan website yang sebelumnya telah dibuat menggunakan HTML. CSS digunakan untuk mengatur warna, jenis dan ukuran huruf, jarak antarbagian, ukuran elemen, posisi konten, navigasi, tombol, artikel, sidebar, dan footer.
Pengaturan layout dilakukan menggunakan properti CSS seperti `display`, `width`, `margin`, `padding`, dan `gap`. Properti tersebut membantu menyusun elemen website agar terlihat rapi dan teratur.
Website menggunakan kombinasi warna pink pastel, putih, dan pink tua. Warna pink pastel digunakan untuk memberikan kesan lembut, warna putih membantu menjaga tampilan tetap bersih, sedangkan pink tua digunakan sebagai aksen agar bagian penting seperti tombol, navigasi, atau judul terlihat lebih menonjol.
Penggunaan warna yang konsisten membuat halaman Home, About, dan Kontak memiliki tampilan yang serasi.

## 4. Membuat File about.html
File `about.html` digunakan untuk menampilkan halaman yang berisi informasi mengenai pemilik website. Kode HTML di dalamnya menyusun bagian profil, deskripsi diri, kemampuan yang sedang dipelajari, dan portfolio proyek latihan.
Elemen HTML digunakan untuk mengelompokkan informasi agar mudah dibaca oleh pengunjung. Halaman About juga dilengkapi navigasi agar pengunjung dapat berpindah kembali ke halaman Home atau menuju halaman Kontak.
Tampilan halaman disesuaikan dengan file CSS agar tetap menggunakan tema desain yang sama dengan halaman utama.

## 5. Membuat File kontak.html
File `kontak.html` digunakan untuk menampilkan halaman kontak yang memungkinkan pengunjung mengisi informasi dan menuliskan pesan melalui form.
Kode HTML pada halaman ini menggunakan elemen `<form>` sebagai wadah formulir, `<label>` untuk keterangan setiap kolom, `<input>` untuk masukan nama dan email, `<textarea>` untuk pesan, serta `<button>` untuk tombol pengiriman.
CSS digunakan untuk mengatur tampilan form agar lebih rapi dan sesuai dengan tema warna website. Form ini merupakan tampilan antarmuka; pengiriman pesan secara nyata memerlukan pemrosesan tambahan.

## 6. Pengujian Navigasi Website
Setelah seluruh file selesai dibuat, dilakukan pengujian melalui browser untuk memastikan halaman website dapat ditampilkan dengan baik. Pengujian dilakukan dengan membuka halaman Home, About, dan Kontak serta mencoba menu navigasi yang tersedia.
Pengujian ini bertujuan memastikan tautan mengarah ke halaman yang sesuai dan tampilan website tetap konsisten.

## 7. Hasil Akhir Praktikum
Hasil akhir praktikum adalah website sederhana yang dibuat menggunakan HTML dan CSS dengan beberapa halaman, yaitu Home, About, dan Kontak. HTML digunakan untuk membangun struktur dan isi halaman, sedangkan CSS digunakan untuk mengatur desain, warna, ukuran, jarak, dan tata letak.
Melalui praktikum ini, dapat dipahami cara membuat struktur halaman website, menghubungkan HTML dengan CSS, menyusun layout, membuat navigasi antarhalaman, serta membuat form kontak dengan tampilan yang konsisten.
